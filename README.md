**Description**
1. This is a sample automation framework using `Java`, `Selenium`, `Cucumber` & `TestNG`
2. Using a sample url `https://www.demoblaze.com/index.html` to automate
3. Browser name, url and other details are configured in `config.properties`
4. **This supports parallel execution**


**How to execute**

1. Create your feature files in `src/test/resources/features`
2. Create your step defnitions in `src/test/java/web/steps`
3. Create your Page objects in `src/test/java/web/pages`
4. Create yout components in `src/test/java/web/components`
5. `feature file -> steps -> page objects -> components`
6. provide the cucumber tag in runner file `src/test/java/runners/Runner.java`

**Happy Automation** **:)**
